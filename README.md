# Propuestas de portada · Posgrados Panamericana

Ocho portadas para la demo de la línea gráfica (Unidad 2, contenido de Scala Learning):
**Propuesta 1** (la actual) a **Propuesta 8**. La barra inferior cambia entre ellas; cada una tiene su
enlace directo: `…/#1` … `…/#8`. Las propuestas 6, 7 y 8 son la 5 (con foto) con el Tahalí en verde
sólido, en contorno dorado y sin él.

Sitio: <https://upanamericana.github.io/propuestas-portada/>

Propuesta pendiente de validar con el cliente. La foto de las propuestas 5 a 8 es de Vitaly Gariev en
Unsplash (<https://unsplash.com/photos/Z6ogoeso9BI>, Unsplash License). Laurentian y Seravek se ven
solo si están instaladas; si no, Crimson Pro y Source Sans 3.

Generado con `componer.js --publicar` desde el OVA Kit; no se edita a mano.
