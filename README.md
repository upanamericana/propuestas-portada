# Propuestas de portada · Posgrados Panamericana

Cinco portadas para la demo de la línea gráfica (Unidad 2, contenido de Scala Learning): **A** la
actual, **B** «A sangre», **C** «Quien aprueba», **D** «Cartel», **E** «Foto». La barra inferior
cambia entre ellas; cada una tiene su enlace directo: `…/#A` … `…/#E`.

Sitio: <https://upanamericana.github.io/propuestas-portada/>

Propuesta pendiente de validar con el cliente. La foto de E es de Vitaly Gariev en Unsplash
(<https://unsplash.com/photos/Z6ogoeso9BI>, Unsplash License). Laurentian y Seravek se ven solo si
están instaladas; si no, Crimson Pro y Source Sans 3.

Generado con `componer.js --publicar` desde el OVA Kit; no se edita a mano.
